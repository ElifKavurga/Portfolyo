# Elif Kavurga | Kişisel Portfolyo

React ve Vite kullanılarak geliştirilen modern, responsive ve minimal tasarıma sahip kişisel portfolyo web sitesi.

## Canlı Demo

https://elifkavurga.github.io/Portfolyo/

---

## Özellikler

- Modern ve responsive tasarım
- React + Vite mimarisi
- Tailwind CSS ile stillendirme
- Framer Motion animasyonları
- Proje vitrini
- Deneyim zaman çizelgesi
- Yetenekler bölümü
- İletişim bölümü
- GitHub Pages ile otomatik deployment

---

## Kullanılan Teknolojiler

| Alan | Teknolojiler |
| --- | --- |
| Frontend | React, Vite, Tailwind CSS, Framer Motion |
| Deployment | GitHub Pages, GitHub Actions |


## Kurulum

```bash
cd frontend
npm install
npm run dev
```

---

## Production Build

```bash
cd frontend
npm run build
```

---

## Deployment

Bu proje GitHub Actions kullanılarak GitHub Pages üzerine otomatik olarak yayınlanır. `main` branch'ine yapılan her push sonrasında frontend bağımlılıkları kurulur, production build oluşturulur ve GitHub Pages'e deploy edilir.
